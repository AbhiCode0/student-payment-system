# Student Payment System

A simple student course-fee payment system developed using Python.

## Features
- Validate student payments
- Calculate outstanding course fees
- Generate payment receipts
- Display student name, course fee, paid amount, and balance

## Concepts Used
- Python functions
- Conditional statements
- Nested functions
- Return values
- String and numeric output

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

```bash
python payment.py
```

## Example
- Student Name: Abhishek
- Course Fee: 12000
- Paid Amount: 12000
- Balance: 0

This project is intended for learning Python programming.
